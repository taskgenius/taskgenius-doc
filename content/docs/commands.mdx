Task Genius registers Obsidian commands for common operations. You can run them from the Command Palette (`Cmd/Ctrl + P`) and bind hotkeys in **Settings -> Hotkeys**.

Notes:
- Some commands only appear when the corresponding feature is enabled in settings.
- Task view switch commands are created dynamically from your configured views (one command per view).

## Views & Navigation

| Command | What it does | Availability |
| --- | --- | --- |
| Open Task Genius view | Opens the main Task Genius view | Always |
| Open Timeline Sidebar | Opens the Timeline Sidebar view | Always |
| Open Task Genius Setup | Opens the onboarding/setup view | Always |
| Open Task Genius changelog | Opens the changelog view | Always (requires changelog manager initialized) |
| Open Task Genius settings | Opens Task Genius settings modal | Always |
| *(Your view name)* | Switches to a specific configured Task Genius view | When Task Genius view configuration exists |

## Capture

| Command | What it does | Availability |
| --- | --- | --- |
| Quick Capture | Opens the Quick Capture modal | Always |
| Minimal Quick Capture | Opens the minimal Quick Capture modal | Always |
| Quick File Create | Creates a file via Quick Capture (location: file) | Always |
| Toggle quick capture panel in editor | Shows/hides the inline quick capture panel | Always |
| Toggle quick capture panel in editor (Globally) | Shows the inline quick capture panel in the active editor | Always |

## Editor Actions

| Command | What it does | Availability |
| --- | --- | --- |
| Toggle task filter panel | Shows/hides the in-editor task filter panel | Always |
| Cycle task status forward | Cycles the task status forward at cursor/selection | Always |
| Cycle task status backward | Cycles the task status backward at cursor/selection | Always |
| Sort Tasks in Section | Sorts tasks under the current heading/section | When **Settings -> Sort Tasks** is enabled |
| Sort Tasks in Entire Document | Sorts all tasks in the current file | When **Settings -> Sort Tasks** is enabled |

## Indexing

| Command | What it does | Availability |
| --- | --- | --- |
| Force reindex all tasks | Clears caches and rebuilds the task index | Always |
| Reindex habits | Rebuilds habit index | When habits are enabled |

## Priority (Keyboard Shortcuts)

These commands are generated from the configured priority system.

| Command | What it does | Availability |
| --- | --- | --- |
| Set priority Highest priority | Sets priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority High priority | Sets priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority Medium priority | Sets priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority Low priority | Sets priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority Lowest priority | Sets priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority A | Sets letter priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority B | Sets letter priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Set priority C | Sets letter priority at cursor | When **Enable priority keyboard shortcuts** is enabled |
| Remove priority | Removes priority at cursor | When **Enable priority keyboard shortcuts** is enabled |

## Move / Archive Tasks

| Command | What it does | Availability |
| --- | --- | --- |
| Move task to another file | Moves the current task to a target file | Always |
| Move all completed subtasks to another file | Moves all completed subtasks (and children) | When completed task mover is enabled |
| Move direct completed subtasks to another file | Moves only direct completed children | When completed task mover is enabled |
| Move all subtasks to another file | Moves all subtasks (completed + incomplete) | When completed task mover is enabled |
| Auto-move completed subtasks to default file | Moves completed subtasks using your default destination | When completed auto-move is enabled |
| Auto-move direct completed subtasks to default file | Moves direct completed children using your default destination | When completed auto-move is enabled |
| Auto-move all subtasks to default file | Moves all subtasks using your default destination | When completed auto-move is enabled |
| Move all incomplete subtasks to another file | Moves all incomplete subtasks (and children) | When incomplete task mover is enabled |
| Move direct incomplete subtasks to another file | Moves only direct incomplete children | When incomplete task mover is enabled |
| Auto-move incomplete subtasks to default file | Moves incomplete subtasks using your default destination | When incomplete auto-move is enabled |
| Auto-move direct incomplete subtasks to default file | Moves direct incomplete children using your default destination | When incomplete auto-move is enabled |
