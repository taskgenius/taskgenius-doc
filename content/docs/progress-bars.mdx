Task Genius automatically adds progress indicators to parent items (tasks, list items, or headings) based on the completion status of their sub-tasks.

## Overview

Progress bars provide visual feedback on task completion, helping you track progress at a glance. They can display as graphical bars, text indicators, or both.

  Open Progress Bar Settings
</DeepLinkButton>
<DeepLinkFallback />

## Example

```markdown
- [ ] Parent Task [||||----] [4/8]
  - [x] Sub-task 1
  - [x] Sub-task 2
  - [/] Sub-task 3 (In Progress)
  - [-] Sub-task 4 (Abandoned)
  - [?] Sub-task 5 (Planned)
  - [x] Sub-task 6
  - [x] Sub-task 7
  - [ ] Sub-task 8
```

## Display Settings

### Progress Bar Display Mode

<VersionCallout version="7.0.0" />

Control how progress is visualized with the `progressBarDisplayMode` setting.

| Mode | Description | Example |
|------|-------------|---------|
| `none` | No progress indicator shown | (hidden) |
| `graphical` | Visual bar only | `[||||----]` |
| `text` | Text indicator only | `[4/8]` |
| `both` | Both graphical and text | `[||||----] [4/8]` |

**Default:** `both`

### Text Format Options

<VersionCallout version="7.0.0" />

When text indicators are enabled, customize their format with `displayMode`:

| Format | Description | Example |
|--------|-------------|---------|
| `percentage` | Percentage complete | `75%` |
| `bracketPercentage` | Percentage in brackets | `[75%]` |
| `fraction` | Completed vs total | `6/8` |
| `bracketFraction` | Fraction in brackets | `[6/8]` |
| `detailed` | Detailed breakdown | `[✓:6 ⟳:1 ?:1 / 8]` |
| `custom` | Custom template | (user-defined) |
| `range-based` | Text based on percentage ranges | (configurable) |

**Default:** `bracketFraction`

### Custom Format Template

<VersionCallout version="7.0.0" />

When `displayMode` is set to `custom`, define output using template placeholders:

**Available Placeholders:**

| Placeholder | Description |
|-------------|-------------|
| `{{COMPLETED}}` | Number of completed tasks |
| `{{TOTAL}}` | Total number of tasks |
| `{{PERCENT}}` | Completion percentage |
| `{{IN_PROGRESS}}` | Number of in-progress tasks |
| `{{ABANDONED}}` | Number of abandoned tasks |
| `{{PLANNED}}` | Number of planned tasks |
| `{{NOT_STARTED}}` | Number of not started tasks |
| `{{COMPLETED_SYMBOL}}` | Symbol for completed status |
| `{{IN_PROGRESS_SYMBOL}}` | Symbol for in-progress status |
| `{{ABANDONED_SYMBOL}}` | Symbol for abandoned status |
| `{{PLANNED_SYMBOL}}` | Symbol for planned status |
| `{{NOT_STARTED_SYMBOL}}` | Symbol for not started status |

**JavaScript Expressions:**

Embed expressions within `${=...}` for dynamic text:

```javascript
${="=".repeat(Math.floor(data.percentages.completed/10))}
```

**Examples:**

```
[{{COMPLETED}}/{{TOTAL}}]                    → [6/8]
{{PERCENT}}% Done                            → 75% Done
[{{COMPLETED_SYMBOL}}:{{COMPLETED}} / {{TOTAL}}] → [✓:6 / 8]
```

### Range-Based Text

<VersionCallout version="5.0.0" />

Define custom text for different completion percentage ranges:

| Setting | Type | Description |
|---------|------|-------------|
| `customizeProgressRanges` | boolean | Enable range-based text |
| `progressRanges` | array | Array of range definitions |

**Range Definition:**

```typescript
{
  min: number,   // Minimum percentage (inclusive)
  max: number,   // Maximum percentage (exclusive)
  text: string   // Text template with `{{PROGRESS}}` placeholder
}
```

**Default Ranges:**

| Range | Text |
|-------|------|
| 0-20% | `"Just started {{PROGRESS}}%"` |
| 20-40% | `"Making progress {{PROGRESS}}%"` |
| 40-60% | `"Half way {{PROGRESS}}%"` |
| 60-80% | `"Good progress {{PROGRESS}}%"` |
| 80-100% | `"Almost there {{PROGRESS}}%"` |

## Counting Configuration

### Count Sub-Levels

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `countSubLevel` | boolean | `false` | Count all nested sub-items, not just direct children |

When enabled, progress includes all descendant tasks. When disabled, only immediate children are counted.

### Show Percentage

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `showPercentage` | boolean | `false` | Show percentage in progress display |

## Target Items

Control where progress bars appear:

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `addProgressBarToNonTaskBullet` | boolean | `false` | Add progress bars to regular list items (not just tasks) |
| `addTaskProgressBarToHeading` | boolean | `false` | Add progress bars to headings with sub-tasks |
| `addProgressBarToProjectsView` | boolean | `false` | Show progress bars in the Projects view |
| `enableProgressbarInReadingMode` | boolean | `false` | Enable progress bars in Reading Mode |

<VersionCallout version="4.0.0" />

Reading Mode support was added in version 4.0.0.

## Conditional Display

### Hide Progress Bar Based on Conditions

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `hideProgressBarBasedOnConditions` | boolean | `false` | Enable conditional hiding |
| `hideProgressBarTags` | string | `"no-progress,hide-progress"` | Tags that hide progress bars (comma-separated) |
| `hideProgressBarFolders` | string | `""` | Folder paths that hide progress bars |
| `hideProgressBarMetadata` | string | `"hide-progress-bar"` | Frontmatter key that hides progress bars |

**Example - Hide by Tag:**

```markdown
- [ ] Task without progress bar #no-progress
  - [x] Sub-task 1
  - [ ] Sub-task 2
```

**Example - Hide by Frontmatter:**

```yaml
---
hide-progress-bar: true
---
```

### Show Progress Bar on Specific Headings

<VersionCallout version="8.6.0" />

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `showProgressBarBasedOnHeading` | string | `""` | Only show progress bars under specific headings |

Use comma-separated heading names to restrict where progress bars appear:

```
## Tasks, ## Todo, ## Project Tasks
```

## Custom Progress Goal

<VersionCallout version="8.0.0" />

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `allowCustomProgressGoal` | boolean | `false` | Enable custom goals via inline fields |

When enabled, use `g::number` to set a custom total:

```markdown
- [ ] Project with custom goal g::10
  - [x] Task 1
  - [x] Task 2
  - [x] Task 3
```

Progress shows `3/10` instead of `3/3`.

## Hover Information

<VersionCallout version="6.0.0" />

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `supportHoverToShowProgressInfo` | boolean | `false` | Show detailed progress on hover |

When enabled, hovering over a progress bar displays:
- Breakdown by status (completed, in-progress, etc.)
- Percentage complete
- Task counts

## Best Practices

### Organizing Tasks for Progress Tracking

```markdown
## Project Alpha
- [ ] Phase 1
  - [x] Research
  - [x] Planning
  - [ ] Implementation
- [ ] Phase 2
  - [ ] Testing
  - [ ] Deployment
```

### Using Custom Formats for Teams

```
[{{COMPLETED_SYMBOL}}:{{COMPLETED}} {{IN_PROGRESS_SYMBOL}}:{{IN_PROGRESS}} / {{TOTAL}}]
```

Output: `[✓:4 ⟳:2 / 10]`

### Excluding Administrative Tasks

Use `#no-progress` tag for tasks that shouldn't affect progress:

```markdown
- [ ] Main Project [4/5]
  - [x] Task 1
  - [x] Task 2
  - [ ] Task 3
  - [x] Task 4
  - [x] Task 5
  - [ ] Notes and References #no-progress
```

## Troubleshooting

### Progress Bar Not Showing

- Check `progressBarDisplayMode` is not set to `none`
- Verify the item has sub-tasks
- Check if conditional hiding rules apply
- Ensure you're in Live Preview or Reading Mode (if enabled)

### Incorrect Progress Count

- Check `countSubLevel` setting
- Verify task status markers match your configuration
- Check excluded markers in Task Status settings

### Progress Bar in Wrong Location

- Review `showProgressBarBasedOnHeading` setting
- Check `hideProgressBarFolders` paths
