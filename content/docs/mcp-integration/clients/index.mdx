## Shared Settings (All Clients)

- **URL**: `http://127.0.0.1:7777/mcp` (or your configured port)
- **Header**: `Authorization`
- **Value**: `Bearer <TOKEN>+<APP_ID>`

If requests fail, see [Troubleshooting](/docs/mcp-integration/troubleshooting).
