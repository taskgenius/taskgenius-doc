This guide assumes you can already create tasks and open the Task View. The goal is to reduce friction and make the UI match how you work.

## <LayoutDashboardIcon className="inline-block" /> Make the Task View match your day

- Pick a default View Mode per view (Inbox/Today/Upcoming/Flagged), then let it persist:
  - [View Modes](/docs/view-modes)
- If you often switch contexts, introduce workspaces:
  - [Workspace](/docs/workspace)

## <FilterIcon className="inline-block" /> Use filtering as your \"focus tool\"

- Use filtering to answer one question at a time:
  - \"Only work tasks\"
  - \"Only this project\"
  - \"Only overdue\"
- In-editor filtering helps when you’re editing a note and want only relevant blocks:
  - [In-Editor Task Filtering](/docs/filtering)

## <LayersIcon className="inline-block" /> Configure statuses that reflect your workflow

If your work is status-driven, invest here:

<DeepLinkButton href="obsidian://task-genius/settings?tab=task-status">
  Open Task Status Settings
</DeepLinkButton>
<DeepLinkFallback />

- Define \"in progress\" / \"blocked\" / \"waiting\" etc. using status marks
- Use cycling rules so switching status is one action, not editing text

Docs: [Task Status & Cycling](/docs/task-status)

## <WorkflowIcon className="inline-block" /> Add automation where it saves time

- Quick capture reduces \"where do I write this task?\" decisions:
  - [Quick Capture](/docs/quick-capture)
- Workflows turn repeated maintenance into one action:
  - [Workflows](/docs/workflows)
- Bulk operations help when you need to clean up a backlog:
  - [Bulk Operations](/docs/bulk-operations)

## <SettingsIcon className="inline-block" /> Tune the UI for your workspace layout

If you want the sidebar/details to behave more like native Obsidian panels:

<DeepLinkButton href="obsidian://task-genius/settings?tab=interface">
  Open Interface Settings
</DeepLinkButton>
<DeepLinkFallback />

Docs:

- [Interface Settings](/docs/interface-settings)
- [UI Layer](/docs/task-view/ui-layer)

## <HammerIcon className="inline-block" /> Suggested \"pick 3\" improvements

- 🧭 Set a preferred View Mode for each core view (Inbox/Today/Upcoming/Flagged)
- 🔁 Configure 1-2 status cycles that match how you actually move work
- 🧱 Create one workspace for \"work\" and one for \"personal\"
