Task Genius keeps tasks as **plain Markdown**, and adds a UI + metadata layer on top:

- <LayoutDashboardIcon className="inline-block w-5 h-5" /> **Task View**: a dashboard for vault-wide task navigation with multiple view modes
- <WrenchIcon className="inline-block w-5 h-5" /> **Editor enhancements**: status cycling, progress bars, and workflow automation in-place
- <SparklesIcon className="inline-block w-5 h-5" /> **Automation**: filters, workspaces, date management, and quick capture

If you land here and don't know what to do next: pick your user level and follow one \"track\".
