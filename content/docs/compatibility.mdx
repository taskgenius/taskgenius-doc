## Tasks Plugin

When using Task Genius alongside the popular [Tasks plugin](https://github.com/obsidian-tasks-group/obsidian-tasks), be aware of potential conflicts. Both plugins manage task statuses and dates, which can lead to unexpected behavior if not configured properly.

### Potential Conflicts

#### 1. Status Cycling Conflicts

Both plugins can cycle task statuses when you click on a checkbox:

| Feature | Task Genius | Tasks Plugin |
|---------|-------------|--------------|
| Click-to-cycle | "Enable click-to-cycle" setting | Built-in behavior |
| Custom statuses | Full customization via Status Cycles | Status types configuration |
| Cycle order | User-defined sequences | Predefined sequences |

**Symptoms of conflict:**
- Clicking a checkbox changes status unexpectedly
- Status cycles in wrong order
- Double status changes on single click

#### 2. Date Management Conflicts

Both plugins can automatically add dates to tasks:

| Feature | Task Genius | Tasks Plugin |
|---------|-------------|--------------|
| Completion date | "Automatic Date Management" | Auto-suggest/edit |
| Start date | On "In Progress" status | Manual or query-based |
| Format | Emoji (✅) or Dataview | Emoji format |

**Symptoms of conflict:**
- Duplicate dates appearing on tasks
- Dates in wrong format
- Dates being removed unexpectedly

### Recommended Configurations

Choose **ONE** of the following setups:

---

### Option A: Use Task Genius for Status Cycling

Best if you want **custom multi-step workflows** (e.g., `[ ] → [/] → [?] → [x]`).

<DeepLinkButton href="obsidian://task-genius/settings?tab=task-status">
  Open Task Status Settings
</DeepLinkButton>
<DeepLinkFallback />

**Task Genius Settings:**
1. Enable "Click-to-cycle" ✅
2. Enable "Custom status workflows" ✅
3. Configure your status cycles as needed

**Tasks Plugin Settings:**
1. Go to Tasks plugin settings
2. Under "Status Settings", set status types to match Task Genius's 5 core categories
3. Disable any conflicting click handlers if available
4. Consider using Tasks plugin only for querying, not status management

---

### Option B: Use Tasks Plugin for Status Cycling

Best if you rely heavily on **Tasks plugin queries** and want consistent behavior.

**Task Genius Settings:**
1. Disable "Click-to-cycle" ❌
2. Disable "Custom status workflows" ❌
3. Keep "Core Status Categories" configured to match Tasks plugin for accurate progress bars

**Tasks Plugin Settings:**
1. Use Tasks plugin's native status cycling
2. Configure status types as needed

---

### Option C: Use Both (Advanced)

For advanced users who want features from both plugins.

**Key principle:** Ensure status markers don't overlap between plugins.

**Setup:**
1. In Task Genius, define cycles for specific workflows (e.g., project management)
2. In Tasks plugin, configure different status types
3. Use Task Genius cycles only in specific notes/projects
4. Use Tasks plugin for general task management

**Example separation:**
- Task Genius: `[P]` (Project), `[R]` (Review), `[B]` (Blocked)
- Tasks plugin: `[ ]`, `[x]`, `[-]`, `[/]`

---

### Date Management Compatibility

If using automatic dates from both plugins:

1. **Choose one plugin for date management**
   - Task Genius: Settings → Task Status → "Automatic Date Management"
   - Tasks plugin: Auto-suggest features

2. **Use consistent date format**
   - Both plugins support emoji format (✅ for completion)
   - Task Genius also supports Dataview format

3. **Disable duplicate features**
   - If using Task Genius dates, disable Tasks plugin's auto-date features
   - If using Tasks plugin dates, disable Task Genius's "Automatic Date Management"

### Troubleshooting

#### Status changes unexpectedly on click

1. Check if both plugins have click handlers enabled
2. Disable one plugin's cycling feature
3. Verify status markers don't overlap

#### Dates appearing twice

1. Check both plugins' date settings
2. Disable automatic dates in one plugin
3. Verify date format consistency

#### Progress bars showing wrong counts

1. Ensure Task Genius's "Core Status Categories" match your actual markers
2. Check "Count unknown symbols as" setting
3. Verify excluded markers in "Progress Calculation" settings
